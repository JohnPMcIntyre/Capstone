## About
McIntyre's Fitness App is a Windows Forms desktop application built in C# and MySQL that allows users to register accounts, log workouts, view training history, track progress statistics, and visualize fitness data over time through a line graph.

## How to Run
1. Install Visual Studio 2022 and MySQL
2. Clone this repository: `git clone https://github.com/JohnPMcIntyre/Capstone`
3. Open MySQL Workbench and create a database called `mcintyrefitness`
4. Create the Users and Workouts tables using the database schema in the portfolio
5. Open the solution in Visual Studio 2022
6. Build and run the project
